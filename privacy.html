Privacy policy

Personal Mail Access is a private tool used only by its owner, on the owner's own Gmail mailboxes.

What it accesses

It uses the Gmail API with read-only permission (gmail.readonly), plus the basic profile information that identifies which mailbox is signed in. It cannot send, change or delete mail.

Where data goes

  • Access tokens are stored encrypted on the owner's own computer. The tool runs no server of its own and keeps no database.
  • Mail is read only when the owner asks. The owner uses an AI assistant (Claude, made by Anthropic) to work with it, so the mail the owner asks about is sent to that assistant to answer the request.
  • Mail is not sold, used for advertising, or shared with anyone else.

Google's rules

Use of data from Google APIs is subject to the Google API Services User Data Policy.

Removing access

Access can be withdrawn at any time on the Google Account connections page.
